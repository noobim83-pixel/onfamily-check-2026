모든 위원회 담당자가 같은 체크 내용을 공유하려면
아래 단계를 따라 한 번만 설정하면 됩니다.

1
JSONBin.io 무료 가입

jsonbin.io 에 접속해서 우측 상단 Sign Up 클릭 → 이메일로 무료 가입합니다.

2
Bin(저장소) 만들기

로그인 후 Bins → Create New Bin 클릭
내용에 {"items":{},"memo":""} 입력 후 저장
→ 상단 URL에서 Bin ID(긴 숫자)를 복사합니다.

3
API Key 복사

우측 상단 프로필 → API Keys → Create API Key
생성된 키를 복사합니다.
